# Hostel Management System

The Hostel Management System is a web-based application designed to streamline and automate various activities within a hostel environment. It facilitates efficient management of student details, room reservations, food ordering, check-in/check-out processes, and payments, thereby reducing manual work and enhancing data security.

## Features

- **Student Management**: Maintain comprehensive records of students, including personal details and payment history.
- **Room Management**: Manage room allocations, track occupancy, and monitor available rooms (AC and non-AC).
- **Admin Access**: Registered administrators can log in to manage records, add rooms, allocate room members, and oversee other hostel operations.
- **Security**: Ensure that only authorized individuals (girls and staff members) have access to the hostel premises.

## Benefits

- **Reduced Manual Work**: Automates routine tasks, minimizing human error and labor.
- **Data Security**: Secures the data of room members, ensuring privacy and integrity.
- **User-Friendly Interface**: Designed to be intuitive and easy for admins to handle.
- **Efficient Record Keeping**: Facilitates easy data updating and backup generation.

## Technologies Used

- **Front End**: HTML5, CSS, JavaScript
- **Back End**: PHP 5.5, MySQL

## Installation

1. **Download and Unzip**: Download the project files and unzip them on your local system.
2. **Move to Server Directory**: Place the unzipped files inside the `xampp/htdocs/` directory.
3. **Database Configuration**:
   - Open phpMyAdmin.
   - Create a database named `hostel`.
   - Import the `hostel.sql` file into the `hostel` database.
4. **Access the Application**:
   - Open your browser and navigate to `http://localhost/hostel/`.
5. **Login Details**:
   - **Admin Login**:
     - URL: `http://localhost/hostel`
   - **User Login**:
     - URL: `http://localhost/hostel`

## Usage

- **Admin Panel**: Admins can log in to manage rooms, allocate students, order food, and oversee hostel operations.
- **Student Access**: Students can log in to view room details and other relevant information.
